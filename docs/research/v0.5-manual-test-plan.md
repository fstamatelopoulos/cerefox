# v0.5.0 — Manual Test Plan

> **Living document.** Filled in as each Part of iteration 23 lands.
>
> The TS unit tests (under `_shared/__tests__/cli-core/` and
> `packages/memory/test/`) cover most of the contract. This document
> covers what they can't:
>
> - Behaviour on a **clean macOS install** (no uv, no clone).
> - Interactive flows (`cerefox init`, prompts).
> - Cross-shell tab completion (bash, zsh, fish).
> - Per-MCP-client config writers (`cerefox configure-agent --tool …`).
> - Three-way npm publish verification (mirrors the v0.4 first-publish
>   gauntlet checklist in Decision Log Q2 Part 3).

Each section has a `**Status**` line that gets ticked as the maintainer runs
through it before signing off a release. v0.5.x patches: only re-run the
sections that match what changed.

---

## 0. Environment matrix

The full surface lives on three matrices:

- **Runtime**: Bun ≥ 1.0, Node ≥ 20 (no LTS-of-LTS yet — Node 20 + 22 sampled).
- **OS**: macOS 14+ (primary), Ubuntu 22.04 (CI), Windows (not in scope for v0.5).
- **Install source**: `npm install -g`, `bun install -g`, `npx --package=` ad-hoc.

A "clean" run = freshly-imaged macOS VM (or `rm -rf ~/.bun ~/.npm-global ~/.cerefox` on the maintainer's machine).
