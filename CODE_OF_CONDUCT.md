# Code of Conduct

Cerefox has adopted the **Contributor Covenant, version 2.1** as its code of conduct for
all project spaces — this repository, its issues and pull requests, its discussions, and
any communication channels operated by the project.

The full, binding text lives at the canonical URL:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project, you agree to abide by it.

## Scope

The code of conduct applies wherever you represent the Cerefox project — in repositories,
discussions, pull requests, issue trackers, social media when posting as a Cerefox
contributor, and any in-person or online event organized under the project's name.

## Reporting

If you experience or witness behavior that violates the code of conduct, report it
privately to the project maintainer at:

**fotis@innovedi.com**

All reports are treated confidentially. The maintainer will acknowledge receipt within a
reasonable period and will follow the enforcement guidelines outlined in the upstream
Contributor Covenant text.
